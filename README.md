# Library Management System (LMS) — MySQL Database Project

A normalized relational database system built in **MySQL 8.0** to manage library book inventory, multi-author cataloging, member borrowing tiers, issue/return workflows, automated fine calculations, and analytical reporting.

**Author:** Duppada Mohan Kumar  
**Database Engine:** MySQL 8.0 (`library_management_db`)
